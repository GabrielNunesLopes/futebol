# 1v1 Football

Jogo local de futebol 2D para dois jogadores no mesmo teclado.

## Controles

- Jogador 1 (vermelho): `A` / `D` para mover, `W` para pular e `S` para chutar.
- Jogador 2 (azul): `←` / `→` para mover, `↑` para pular e `↓` para chutar.

## Regras

- Partida de 3 minutos.
- Primeiro a 3 gols vence imediatamente.
- Se o tempo acabar empatado, entra em Golden Goal.
- O Super Chute carrega ao manter domínio real da bola por aproximadamente 2,75 segundos.

## Rodar no localhost

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite, normalmente `http://localhost:5173`.
